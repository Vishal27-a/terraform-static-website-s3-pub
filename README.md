# 🚀 Terraform Static Website Hosting on AWS S3

This project demonstrates how to deploy a static website on AWS S3 using Terraform.



## 📌 Features
- Infrastructure as Code using Terraform
- AWS S3 Static Website Hosting
- Public access configuration using bucket policy
- Automated HTML deployment



## 🛠️ Tech Stack
- Terraform
- AWS S3
- HTML, CSS, JavaScript
